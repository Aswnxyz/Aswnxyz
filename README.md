## Selected work

### [QZEN — digital queue management](https://github.com/Aswnxyz/qzen)
Helps businesses manage waiting customers through shareable queues, customer tickets and an operator dashboard. The implementation includes queue sessions, history and analytics, Socket.IO updates, browser push notifications and authenticated MCP tools.

**Next.js · TypeScript · MongoDB · Better Auth · Socket.IO**

### [AUREL — interactive fragrance concept](https://github.com/Aswnxyz/aurel-luxury-fragrance)
A fictional fragrance-house website exploring scroll-controlled video, editorial layouts and GSAP motion. Includes responsive layouts and a still-image experience for reduced-motion preferences.

**JavaScript · CSS · Vite · GSAP · Lenis** — [View concept](https://aurel-luxury-fragrance.vercel.app)

### [ZORO — social networking for bikers](https://github.com/Aswnxyz/Project_ZORO-social-network-for--bikers)
A multi-service project covering posts, communities, events, messaging and notifications. It demonstrates RabbitMQ request/reply and event messaging, service-specific data models, and Docker/Kubernetes configuration. Deployment and security hardening remain areas for further work.

**React · Express · MongoDB · RabbitMQ · Socket.IO · Docker**

### [Expense Tracker — browser-based expense management](https://github.com/Aswnxyz/expense-tracker)
An expense dashboard with filtering, validation and shared React state. A typed repository interface separates the UI from browser localStorage; there is no backend database or cross-device sync.

**Next.js · TypeScript · React Context · Tailwind CSS**

### [ShopZen — e-commerce workflows](https://github.com/Aswnxyz/Project_ShopZen)
An Express/EJS application with product administration, cart and wishlist flows, orders, returns and PDF invoices. Payment integration code is included; this is a portfolio implementation that needs security remediation before real commerce use.

**Node.js · Express · EJS · MongoDB · Razorpay · PDFKit**
